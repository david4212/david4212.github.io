# Передача роботи: наповнення бази «НМТ на 200»

## Мета
Наповнити сайт якісними тестами у форматі реального НМТ з 4 предметів (укр. мова, історія, англійська, математика), щоб учень, який пройшов усе, міг написати на 170+. Для кожної теми: **3 тести × 50 питань** (testLevel 1 — легкий, 2 — складніший, 3 — дуже складний), пояснення до кожного питання, картки (flashcards) і **малюнки** (карти, графіки, схеми, ілюстрації — SVG, які малюємо самі). Реальні тести НМТ/ЗНО — лише зразок формату, не копіювати.

Рішення користувача: комітити й пушити одразу в `main`; без зайвих запитань (обирай найкращий варіант сам); відповіді короткі, без вступів. Користувач хоче МАКСИМУМ малюнків (карти, графіки, діаграми, схеми — на НМТ вони є завжди) і дуже високу якість.

## Генератор (`tools/content-gen/`, Python 3)
Запускати з будь-якого місця; шляхи відносні до репозиторію. Новий файл виводиться в `content/math/`, SVG — у `public/img/math/`.
- `mgen.py`: `Topic(idx, slug)`, `fmt`, `ffmt` (дроби a/b, мінус U+2212), `poly(coefs, var)`, `T.add(lv, text, ans, wrongs[(value, reason)], trap, sol, img=None)` — на рівні 1 бере 3 хибні варіанти, на 2–3 — до 4 (5 варіантів, якщо ≥4 різних хибних); дедуплікує за `fmt(value)`; якщо <4 варіантів — `ValueError("мало хибних варіантів")` (це нормально, `T.run` пропускає). Нечислові варіанти перемішуються за хешем тексту, числові сортуються. `T.run(FAMS, target=68)` ганяє родини по колу до 6 спроб із фіксованим seed; `T.save(cards)`; `cleanup_imgs(T)` видаляє SVG, на які ніхто не посилається.
- `msvg.py`: SVG-бібліотека (`C` полотно, `Axes` з `curve` (обрізка за y), `point`, `seg`, `label`, `pie`, `bars`, `poly_label`, `side_label`, `right_angle`, `angle_arc`, `S.tag(...)` для імен файлів, `dec`).
- Приклади родин: `t1.py`…`t4b.py` (текст), `t1_img.py`…`t3_img.py` (малюнки), `t*_cards.py` (картки), `run1.py`…`run3.py` (запуск: `FAMS` + `T.run` + `T.save(cards)` + `cleanup_imgs`). Для теми N робити за зразком теми 3: `tN.py` → `tN_img.py` (`from tNb import *`, `FAMS = [...] + IMGF + IMGF` — подвоєння малюнкових родин збільшує частку питань із картинками) → `tN_cards.py` → `runN.py`.
- Тестові утиліти: `python3 test_fams.py <модуль>` (модуль має мати `FAMS`; друкує вихід по (родина, рівень) і помилки), `python3 review.py <модуль> lo hi` (по одному зразку на родину).
- Перегляд SVG: `rsvg-convert` + ImageMagick `montage` (рендерити лише нові файли, склеїти в PNG і подивитись).

## Правила якості (обов'язково)
- Відповіді рахуються кодом, ніколи не «з голови». Кожен хибний варіант має причину, що описує реальну помилку й збігається з обчисленим значенням (конкретні числа, без зайвих літер).
- Пояснення: `💡 Пастка` / `❌ Хибні` / `✅ Правильна` (це робить `T.add`). Від'ємні числа в поясненнях у дужках (`pn()`), мінус — U+2212, української граматики дотримуватись («Яке з тверджень…»).
- Для малюнкових задач: читаний із сітки малюнок (цілі координати, підписані точки), відповідь однозначно випливає з малюнка; хибні варіанти справді хибні (перевіряти числово).
- Після генерації: `node scripts/validate-content.mjs` має дати OK; оглянути вибірку SVG очима; потім коміт і пуш.

## План малюнкових родин для теми 4 (`t4_img.py`)
Ламана з цілими вершинами (значення, нулі, область визначення/значень з відкритими/закритими кінцями, проміжки зростання/спадання, знак f(x), кількість розв'язків f(x)=a, сума/кількість цілих значень); пряма (рівняння, нуль, площа трикутника, перетин двох прямих); парабола (формула, знаки a, b, c, проміжки монотонності, область значень); показникова/логарифмічна (формула за точками, асимптота); sin/cos (A, період, середня лінія, формула) із позначками π; гіпербола k/(x−a)+b з пунктирними асимптотами; перетворення графіків (f синій, g помаранчевий — обрати формулу, перевіряти числово, що хибні варіанти не збігаються з g); точкові графіки арифметичної/геометричної прогресій; обернена функція та композиція за двома графіками; парність за графіком; періодична ламана (f(N)); кускова функція з порожніми й зафарбованими точками.
